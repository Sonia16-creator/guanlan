    金融机构 券商 / 基金 / 家办

    全球重大事件发生后，你要回答的是：它会传导到哪个板块、哪只股票，盈利和估值会不会变。观澜把事件推演成三种走向，落到板块、个股，再接到财务模型的每股收益和目标价。

    价格波动型行业 航运 / 大宗商品 / 矿业

    你的利润跟着一个价格走：运价、油价、矿价。一条海峡出事、一个产地停产，价格当天就动。观澜盯地缘、航道、制裁和供给，推演价格往哪走、概率多大，过了你设的门槛就提醒。

    出海企业 海外资产持有企业 / 出海制造企业

    你在海外有资产、工厂或市场，最怕的是当地规则突然改变：特许权被审查、关税终裁、工厂审批被否。观澜用当地语言盯监管、议会、法院和媒体，推演这件事会不会碰到你的资产和订单。

    运价到利润：五步传导 运价涨不等于船公司赚钱 · 推演会按这五步判断

    1承运量航线中断、绕行和港口拥堵先改变能运多少货。
    2实现运费长约和船期滞后让公司拿到的运费不等于即期指数，两者的比例每季都在变。
    3附加费与每箱收入每箱收入是运费叠加附加费后的结果，通常高于披露的平均运费。
    4变动成本燃油、货物处理、港口、代理等随业务量和油价变动。
    5准固定成本折旧和租入运力的租金不随运价变动，运价涨时放大利润，跌时放大亏损。

    利润是前三步的收入减去后两步成本的残差。所以同一个事件，对租入运力多的公司和自有船多的公司、长约多的公司和即期多的公司，影响方向和幅度都可能不同。航运类推演会单独给出「运价到利润」一表，验证节点优先用季度运量、平均运费、单箱收入、成本细分和租赁成本。

      情景推演 三种走向 + 概率 + 触发条件 + 验证节点

      情景 A · 保留（修订条款）

      约 45%
      触发条件：听证后转入「修订条款」路径，中菲政府谈判落地，无收回提案成法。
      影响：短期股价波动后企稳；长期合规与可靠性投入上升。
      时间窗口：6–12 个月。
      验证节点
      • 好转 修正案未进入表决，或条款温和
      • 恶化 修正案附加强制退出 / 股权限制条款

      情景 B · 到期不续 / 部分收回

      约 40%
      触发条件：国会通过特许权修正案，或可靠性指标持续不达标，到期（2027）不再全额续期。
      影响：核心资产减值、股东回报大幅下降、融资条款触发。
      时间窗口：12–24 个月。
      验证节点
      • 好转 续期谈判启动，或政府明确续期意向
      • 恶化 修正案成法、或续期被正式否决

      情景 C · 立即收回 / 国有化

      约 15%
      触发条件：以国家安全为由启动收回程序，或出现重大电网事故、中菲关系急剧变化。
      影响：投资重大损失、被迫退出市场，触发最高级别上报。
      时间窗口：突发，需即时响应。
      验证节点
      • 好转 政府澄清无收回意图
      • 恶化 政府正式启动收回或国有化程序

      • 当事方公告 只有一方的原始公告

      • 同源转载 多篇报道出自同一来源，只算一个信源

      关于命中：我们不卖预言，卖可验证

      历史不会重演，但会押韵——结构会重复，时点和幅度每次都不同。所以我们不承诺"预测准"，只承诺"该看见的风险提前让你看见、验证节点提前写清楚、到期自动对账"。

      • 命中率只算"有到期日且已到期"的推演，未到期只展示、不纳入。
      • 虚线推演没发生时，复盘反而证明"诚实区分了已发生与待验证"，而非事后诸葛亮。
      • 说对了留下，说错了也留下——错了认账、事事有据，才是信任的来源。
