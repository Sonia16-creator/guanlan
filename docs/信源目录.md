# 观澜 Horizon · 信源目录 v1

整理日期：2026-11-14。目录按网站现有规划组织，分为四个子目录：海外能源、航运（八层）、券商（五层）、大宗商品敞口，另加行情数据插件。

每个 RSS 地址都在 2026-11-14 用程序实际访问过。「已验证」的标准是能读到条目，而且最近 30 天内有更新。

## 怎么读这份目录

| 标记 | 含义 |
| --- | --- |
| ✅ 已接入 | 已经写进 `pipeline/sources.json` |
| 🟢 可直接接 | RSS 已验证可用，加一行配置就能接入 |
| 🔎 关键词检索 | 官网拦截程序访问或没有 RSS，改用 Google News 按关键词或站点检索；本轮抽测的检索式都能出结果 |
| 🔌 数据接口 | 结构化数据（JSON/CSV），需要在 `run.py` 里写一个小的读取器 |
| 🕸 网页抓取 | 没有 RSS 也没有接口，只能抓网页，维护成本高，放后面 |
| ⛔ 授权 | 付费或需要商用授权，属于 L2，签约后再接 |
| ❓ 未验证 | 本轮没测通或没测，接入前要再确认 |

**优先级：** P0 = 第一批就接；P1 = 第二批；P2 = 有需要再接。

**许可提醒（重要）：** 「免费」不等于「可商用」。观澜是对外销售的产品，所以标了 ⚠ 的信源，正式商用前要看对方条款。
- **Google News RSS 和 Bing News**：只当「发现线索」的入口，正文以原站为准，不整段转载。
- **OpenSanctions**：商用需要付费授权。
- **LBMA 金银价、Baltic Exchange 指数**：商用都需要授权。

## 7. 接入建议

**第一批（P0，大约 45 条）**
- 海外能源：在已有的基础上，加三国的议会信源（巴西两院 RSS，菲律宾参众两院检索）、行业媒体（Electromineria、CanalEnergia、BusinessWorld）和 DF、Valor。
- 航运：补齐八层里的空白：
  - ⑤ 货物层：EIA、Mining.com、OPEC、海关
  - ⑧ 天气层：JTWC
  - ④ 政策层：先用检索补
  - 另外加上 TradeWinds、Seatrade、한국해운신문、Panama Canal 官网、Loadstar
- 大宗商品：OPEC+、EIA、LNG Prime、CFTC，再加美联储。
- 券商：先接宏观层，即美联储、日本央行、韩国央行、HKMA、香港证监会、统计局；再接自身与信用层的检索模板。

**`run.py` 需要的改动**
- 读取 RSS 时跟随 308 跳转（TCU、Offshore Energy 需要）。
- 给 SEC 请求加带联系邮箱的请求头。
- 多条 GDELT 信源之间至少间隔 5 秒。
- `sector` 字段新增 `securities` 和 `commodity`，网站「实时信源」页的筛选同步加上这两项。

**待测**：所有 ❓ 项，以及被 403 拦截的官网。从 GitHub Actions 的服务器访问，结果可能和本机不同，第一次运行后看「信源健康」表就能知道。
